# VibeCraft

PlanCraft 기획서 이후 구현 단계로 이어지는 바이브코딩 학습 코치 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

기본 주소는 `http://127.0.0.1:3000`입니다.

## 구현된 MVP

- 역할 선택: 학생, 선생님, 일반인
- 시작 방식 선택: PlanCraft 기획서 업로드 또는 아이디어 입력
- 추천 생성 API: `/api/analyze-plan`, `/api/idea-interview`
- 기획서 없이 2~4단계 미리보기 (진행률·완료 상태 변경 없음)
- 제작 복잡도 4단계: 한 화면 실습, 작은 웹앱, 확장형, 고급 서비스

- 도구 선택: Codex, Claude, Antigravity
- 서비스 유형 선택: 웹, 모바일 최적화 웹앱, SW/자동화 도구
- 체크리스트 기반 실습 모드
- 용어 사전
- 프롬프트 템플릿
- 에러 해결 도우미
- 배포 전 최종 점검
- 데스크톱 우측 챗봇 패널, 모바일 전체화면 챗봇 시트

복잡도는 `1. 시작하기`에서 역할 선택 바로 아래에 있습니다. 기획서를 분석한 뒤에는 `2. 설계하기`와 `3. 만들기` 상단에서도 바꿀 수 있습니다. 각 선택 카드에는 만들 기능·화면 범위와 예시를 표시합니다.

## 현재 AI 동작 방식

서버 라우트는 Gemini를 우선 호출하고 실패하면 Claude로 대체 호출합니다. 선택한 제작 복잡도는 기획서 분석, 아이디어 분석, 프로젝트 코치와 복사하는 프롬프트에 전달됩니다. 한 화면 실습에서는 브리프를 핵심 기능 하나, HTML·CSS·JavaScript, 세 가지 제작 작업으로 제한합니다.

복잡도 설정은 외부 코딩 도구에 전달하는 제작 지침입니다. 외부 도구가 실제로 생성하는 파일 수를 기술적으로 제한하지 않으므로, 코드를 만들기 전 파일 목록과 예상 개수를 확인해야 합니다. 이미 만든 브리프의 복잡도를 바꾸면 새 프롬프트에는 즉시 반영되지만 브리프와 작업 목록은 다시 분석해야 갱신됩니다.

## Neon DB
